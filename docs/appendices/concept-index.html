动态图：从概率入口到桥梁力学

  • 试块为什么要压很多个：试块点、概率密度与 95% 保证率。
  • 试块的数怎样走进设计：样本、标准值与设计值不是同一个数。
  • 从两条曲线到联合分布：边缘分布、同次配对、失效边界与联合曲面。
  • 车在动，谁在看：右支座反力与跨中弯矩的两条影响线。
  • 相似放大为什么会吃亏：自重需求与截面能力的增长速度。
  • 一股力怎样走到地基：先追力，再说构件名称。
  • 梁高为何比加宽更灵：惯性矩里的三次方。
  • 拱轴线为何要靠近压力线：轴压与附加弯矩。
  • 索放低一点，拉力会怎样：垂度与水平分力。
  • 偏载为什么会把弯矩送进塔：两侧索力不平衡。
  • 温度变化时，支座在替谁让路：自由伸长与完全约束。
  • 两边悬臂为何要一段段配平：未平衡弯矩。
  • 风速翻倍，平均风力为何约四倍：平方关系的前提。
  • 什么时候同样的推力会越推越大：频率比、阻尼与共振入口。
  • 网格画细，答案就可信吗：有限元离散、收敛与基准。
