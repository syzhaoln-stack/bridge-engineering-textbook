## 数字孪生模型的复用与边界

本版没有把有限元只画成“漂亮的网格”。第 18 章的板桥实验台和第 7 章的拱桥实验台复用了作者数字孪生项目中已经验证的单文件版本；复制到本书 `interactive/` 后，均可离线运行。

- 板桥模型：桥面板由 MITC4 平壳单元表示，适合观察横向分布、局部板响应和移动荷载位置变化；它不是车桥耦合动力分析。
- 拱桥模型：48 个板壳单元与 131 个空间梁单元组成混合体系，传力顺序为“桥面板/纵横梁 → 立柱 → 双拱肋 → 四个拱脚”。浏览器代表工况中，竖向荷载传递闭合率为 100.0%。
- 斜拉桥与悬索桥工具：用于看清构造关系、索力增量与传力方向。斜拉桥的 `N0` 是教学基准值，悬索桥的基准水平力来自抛物线索的闭式估算；均未执行成桥索形寻找、施工阶段调索、吊杆松弛或全桥几何非线性验算。
- “纵横梁格”层采用距离加权分担帮助学生形成直觉；真正的板壳横向分布问题转入 MITC4 实验台求解。界面会明确区分“解析示意”“分担近似”和“实际有限元求解”。
