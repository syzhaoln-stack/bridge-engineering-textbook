# 概率、可靠度与影响线：动画分镜

## 统一视觉

- 画幅：16:9，1280×720，30 fps；背景为偏暖纸白 `#F4F0E6`。
- 抗力、可承受、保证区间：青蓝 `#24A8B5`；荷载、失效侧：珊瑚红 `#E36B5D`；当前关注量：琥珀黄 `#E7A93B`。
- 中文只保留问题、变量名和一句结论；公式使用 MathTex，图形先于术语出现。
- 每个镜头只承担一个变化。相同对象通过 Transform/ReplacementTransform 延续，不突然换一套图。
- 动画无配音也能读懂；嵌入教材后由相邻正文补充边界与术语。

## 01 试块为什么要压很多个（约 42 秒）

**要回答的问题：** 同一批混凝土，为什么不能只压一个试块，也不能直接拿平均值去设计？

1. 六个 150 mm 立方体依次出现，压力机压下；每次破坏后在数轴上留下一个强度点。（7 s）
2. 点逐渐增加，堆成直方图，再平滑成概率密度曲线。标出均值 `μ`，画面问：`C50 是平均值 50 吗？`（8 s）
3. 均值左侧出现特征值 `f_cu,k = μ - 1.645σ`。曲线右侧从特征值起着青色，面积标为 `95%`；左尾淡红，标为 `5%`。（10 s）
4. `C50` 落到特征值位置，旁边只留一句：`C50：立方体抗压强度标准值 50 MPa`，并明确 `不是平均值`。（7 s）
5. 收束：多个试块、分布、95%区间同时留在画面，结论 `多做试块，不是为了把数字做得热闹，而是为了看见离散。`（3 s）

**边界：** 不在动画里固定某一本规范的 C50 轴心抗压设计值；不同标准与版本应查相应表格。

## 01B 试块值为什么不能直接算桥（约 12 秒）

**要回答的问题：** 试块压出的 50 MPa，能不能原封不动作为构件设计值？

1. 立方体试块出现，只标 `立方体标准值 f_cu,k`。（3 s）
2. 箭头指向受压构件，标 `构件受力状态 f_ck`。（3 s）
3. 再指向结构设计，标 `设计值 f_d`；只保留抽象关系 `f_d=f_k/γ_M`。（4 s）
4. 收束：`试块给证据，不直接替构件作决定。`（2 s）

**边界：** 动画不代替标准中的强度换算、分项系数与表格取值。

## 02 从两条曲线到联合分布（约 55 秒）

**要回答的问题：** 平均抗力大于平均荷载，为什么仍可能失效？

1. 一维横轴上出现荷载 `S` 的珊瑚曲线、抗力 `R` 的青色曲线；均值相隔明显。（6 s）
2. 荷载曲线向右漂、抗力曲线向左漂；两条尾部开始相遇。字幕：`最不利：荷载偏大，抗力偏小，而且赶到同一次。`（8 s）
3. 一维横轴拆成二维平面：横轴 `S`、纵轴 `R`。一对一对的样本落成散点，而不是把两条边缘曲线重叠当作失效概率。（9 s）
4. 画出边界 `R=S`。上侧青色写 `可承受`，下侧珊瑚色写 `失效`；散点在失效侧的少数被点亮。（7 s）
5. 散点融成等高线，再隆起为联合概率密度曲面；镜头缓慢转动约 45°，失效侧曲面尾部保持红色。（12 s）
6. 在 `R=S` 上点亮当前示意分布中密度较高的位置，不把它冒充规范结论；公式依次出现：`g=R-S`、`P_f=P(g<0)`。（8 s）
7. 收束：`可靠度问的不是“会不会”，而是留给失效侧的概率有多大。`（5 s）

**边界：** 动画用独立正态变量作教学示意；真实工程需要按变量分布、相关性、极限状态和规范模型重新建立。

## 03 影响线：车在动，谁在看（约 42 秒）

**要回答的问题：** 同一辆车，为什么“最不利位置”会随着你关注的量而改变？

1. 一辆车从简支梁左端驶入。梁上先固定一个观察目标：右支座反力。（5 s）
2. 车每前进一步，右支座旁的箭头随之增长；下方同步留下一个点，连成从 0 到 1 的斜线。（10 s）
3. 车辆回到左端，观察目标换成跨中弯矩；下方旧线淡出，新的三角形曲线随车移动长出来。（10 s）
4. 在曲线峰值处停车，把车辆位置和峰值用一条虚线相连；显示 `E=P·y(x)`。（7 s）
5. 两条影响线并排短暂出现：同一辆车，两个目标，两处“最不利”。（6 s）
6. 收束：`别急着问车停在哪里。先说清楚，你替哪个位置、哪种效应守着。` 下方补术语：`固定截面（或反力）对移动单位荷载的响应图。`（4 s）

**边界：** 只演示准静态、线弹性、简支梁与集中荷载；车速没有物理含义，多车、横向分布、连续梁和几何非线性在正文交互中另行讨论。
