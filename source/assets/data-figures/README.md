# 桥梁工程数据图（教学示意）

本文件夹包含六张用于零基础学习者的低认知负荷图。每张图均有 PNG（300 dpi）、SVG（可缩放）和同名 CSV；所有数列为可复现的理论或教学示意数据，**不是实桥现场测量值，也不能直接用于设计**。

## 生成方式

在本文件所在书籍目录的上两级目录中运行：

```powershell
python assets/code/data-figures/generate_data_figures.py
```

需要 Python、NumPy 和 Matplotlib。源码固定了纸白、青蓝、珊瑚和琥珀色的教学视觉语言，并将曲线名称直接标在曲线末端，避免图例墙。

## 图与公式

| 文件前缀 | 问题与无量纲量 | 数据依据 |
| --- | --- | --- |
| `01-scale-selfweight-capacity` | 尺度 `λ`；自重弯矩比 `λ⁴`，几何相似截面能力比 `λ³` | 量纲分析；同材料、完全几何相似，只比较自重。 |
| `02-depth-stiffness-deflection` | 梁高比 `h/h₀`；`I/I₀=(h/h₀)³`，`δ/δ₀=(h/h₀)⁻³` | 等比例截面、跨径与材料不变的线弹性小挠度比较。 |
| `03-cable-sag-horizontal-force` | 垂度比 `f/f₀`；水平力比 `H/H₀=f₀/f` | 均布竖向荷载的理想抛物线索；忽略索自重与大位移。 |
| `04-wind-speed-square-law` | 风速比 `V/V₀`；风力比 `F/F₀=(V/V₀)²` | `F=½ρCᴅAV²`，固定 `ρ`、`Cᴅ`、迎风面积 `A`。 |
| `05-single_dof_dynamic-amplification` | `r=ω/ωₙ`；稳态放大系数 | `1/√[(1-r²)²+(2ζr)²]`；线性单自由度、简谐外力、稳态。 |
| `06-simply-supported-beam-mesh-convergence` | 单元数 `N`；误差百分比 | 解析挠度 `δmax=5qL⁴/(384EI)`；误差列**显式设定为教学二阶模型** `80/N² %`，非实测也非某一软件计算输出。 |

第六图的解析示例取 `L=10 m`、`q=20 kN/m`、`E=30 GPa`、`I=0.12 m⁴`，解析跨中挠度约为 `0.723 mm`。其他图的纵横坐标均是相对于基准状态的无量纲比值。
