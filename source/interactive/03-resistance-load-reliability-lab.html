ρ = 0 是本页的基本情形：两个波动彼此独立。ρ > 0 表示两者较常同涨同落，ρ < 0 表示一涨一落较常同时出现。相关性改变的是两者之差的波动，不能只凭“正相关更危险”或“负相关更安全”下结论。

先说不变的关系，再给它一个名字

平均值之间留出的距离，要和波动的宽度一起看。

“平均抗力大于平均荷载”只说了两个中心的位置；它没有消掉尾部。波动越宽，越多情形可能越过边界。真正需要数的是边界错误一侧的概率质量，而不是只盯着两个峰顶。

把抗力—荷载换成库存—需求、算力—流量或排水能力—暴雨，这个问法仍然成立；只是分布、相关性和越界后果必须重新取证，不能把这张图原样搬过去。

理论值描述给定分布；样本值只描述这一批有限抽样。样本数很少时，即使理论概率不为零，也可能一次都没有抽到。

把刚才看到的写成公式

Z = R − SσZ = √(σR² + σS² − 2ρσRσS)β = (μR − μS) / σZPf = Φ(−β)

初始情形取 ρ = 0，R 与 S 相互独立，所以 σZ = √(σR² + σS²)。“可靠指标 β”就是均值差里能放下多少个“差值的标准差”；Pf 是 Z < 0 的理论概率。
